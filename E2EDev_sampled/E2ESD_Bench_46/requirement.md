1. When the user opens the web page, the system must automatically detect the current day of the week using the user's local date settings and display the corresponding day name.
2. Upon loading the web page, the system must display a predefined quote associated with the current day of the week.
3. The system must ensure that the content updates (day name and quote) occur immediately upon page load without requiring any user interaction.
