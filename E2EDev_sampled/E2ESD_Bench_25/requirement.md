prompt: Develop an image like interaction web application.

1. When the user double-clicks on the image area, the system should display a heart icon at the click location within the image area.
2. When the user double-clicks on the image area, the system should increment the like counter by one.
3. The heart icon created upon a double-click should be removed from the image area after 1 second.
4. The system should differentiate between single and double clicks on the image area, only triggering the heart creation and like counter increment on a double-click.
5. The instruction text should inform the user to double-click on the image to like it, with a heart icon displayed for emphasis.
6. The like count text should display the total number of times the image has been liked, updating dynamically with each double-click.
