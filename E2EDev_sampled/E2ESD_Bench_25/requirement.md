- When the user double-clicks on the image area (div with class 'loveMe'), the system should display a heart icon at the click location within the image area.
- When the user double-clicks on the image area, the system should increment the like counter displayed in the span with id 'times' by one.
- The heart icon created upon a double-click should be removed from the image area after 1 second.
- The system should differentiate between single and double clicks on the image area, only triggering the heart creation and like counter increment on a double-click.
- The instruction text should inform the user to double-click on the image to like it, with a heart icon displayed for emphasis.
- The like count text should display the total number of times the image has been liked, updating dynamically with each double-click.
