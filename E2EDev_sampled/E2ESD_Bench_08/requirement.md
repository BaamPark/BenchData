1. When the user clicks the 'navbar-toggler' button, the navigation menu should expand or collapse, allowing access to navigation links.
2. When the user enters a search query in the 'search-input' field and clicks the 'search-button', the system should initiate a search operation.
3. When the user fills out the 'my-library-form' with a user name, book name, and selects a book type, and clicks the 'add-book-button', the system should validate the inputs and add the book to the list if valid.
4. When the user clicks the 'delete-button' associated with a book entry in the table, the system should remove the book from the list and update the display.
5. When the page loads, the system should display the list of books stored in local storage in the table body.
6. When the user submits the 'my-library-form', the system should display an alert message indicating whether the book was successfully issued or if there was an error (e.g., book already issued).
7. When the user selects a book type using the radio buttons ('fiction-radio', 'programming-radio', 'cooking-radio'), the system should update the selected book type value accordingly.
8. When the user clicks the close button on an alert message, the system should dismiss the alert.
