1. When the user enters a value in the 'Height in cm' input field, the system should accept and store this value for BMI calculation.
2. When the user enters a value in the 'Weight in kg' input field, the system should accept and store this value for BMI calculation.
3. When the user clicks the 'Calculate' button, the system should calculate the BMI using the formula weight (kg) / (height (m) * height (m)) and display the result rounded to two decimal places in the 'result' display area.
4. The system should display a table with BMI ranges and corresponding categories (Underweight, Ideal, Overweight, Obesity) for user reference.
5. When the user views the footer, the system should display social media links (Facebook, GitHub, Twitter, LinkedIn) that open the respective profiles in a new tab when clicked.
