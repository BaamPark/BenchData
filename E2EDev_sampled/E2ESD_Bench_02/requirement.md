- [ ] The system shall allow users to create a new note by clicking the 'Add note' button, and the new note shall open in an empty editable state.
- [ ] The system shall display note content with Markdown formatting in the main view while users edit note text.
- [ ] The system shall let users toggle each note between read mode and edit mode using the 'Edit' control.
- [ ] The system shall allow users to delete a note with the 'Delete' control, and the deleted note shall no longer appear in the note list.
- [ ] The system shall preserve previously created notes so they are available when the user opens the application again.
- [ ] The system shall save note changes as users edit so the latest version is retained without requiring manual export.
