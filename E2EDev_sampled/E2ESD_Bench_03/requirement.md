1. When the user selects a movie from the dropdown menu, the system updates the ticket price for the selected movie.
2. Upon clicking an available seat, the system toggles the seat's selection status, updates the count of selected seats, and calculates the total price.
3. When the page loads, the system restores the user's previously selected movie and seats and updates the interface accordingly.
4. The system displays the number of selected seats and the total price dynamically as the user interacts with seat selections and movie choices.
5. The user can view the status of seats (available, selected, occupied) visually, with occupied seats being non-interactive.
